# 图丫

图丫是一款 Windows 照片管理软件，支持相册整理、分级标签、人物分类、日期浏览、离线位置地图和照片预览。

本仓库仅用于分发 EXE 安装包和发布更新公告，不提供图丫应用源码。

## 下载与更新公告

正式发布的安装包和每个版本的更新公告统一在 [Releases](https://github.com/666Dean/tuya/releases) 提供。下载对应版本的 `.exe` 安装程序，正常关闭图丫后再安装。

当前独立新版正在验收，尚未发布安装包。

系统要求：Windows 11 x64，支持 AVX2 的 Intel 或 AMD 处理器。

支持更新检查的版本可通过“设置 → 软件更新”查看新版公告和下载入口。尚未接入更新检查的旧版本，需要先手动安装支持更新检查的版本。

安装包不包含维护者的照片、图库数据库、账号或个人配置。
