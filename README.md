# 图丫

图丫是一款 Windows 照片管理软件，支持相册整理、分级标签、人物分类、日期浏览、离线位置地图和照片预览。

## 下载与更新公告

安装包和每个版本的更新公告统一在 [Releases](https://github.com/666Dean/tuya/releases) 提供。下载对应版本的 `.exe` 安装程序，正常关闭图丫后再安装。

系统要求：Windows 11 x64，支持 AVX2 的 Intel 或 AMD 处理器。

从 2.0.2 起，可在“设置 → 软件更新”中检查新版并阅读公告。2.0.0、2.0.1 用户需要先手动升级一次。

## 个人图库

照片保持原位置。个人图库数据保存在 `%LOCALAPPDATA%\Tuya`，卸载时保留个人图库数据。

本仓库仅用于分发 EXE 安装包和发布更新公告。
